# 📚 AI Kids Content Studio

An AI-powered web application that generates engaging children's educational content using Large Language Models.

## 🚀 Features

- 📖 AI Story Generation
- 🖼 AI Image Generation
- 🎬 Video Prompt Generation
- 🎙 Voice-over Script Generation
- ❓ Quiz Generation
- 📄 Download Complete PDF
- 💾 Download Story & Image Prompt

## 🛠 Tech Stack

- Python
- Streamlit
- OpenRouter API
- Pollinations AI
- ReportLab
- Pillow

## 📂 Project Structure

```
AI-Kids-Content-Studio/
│
├── app.py
├── utils.py
├── prompts.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Installation

```bash
git clone https://github.com/DeekshaMD15/AI-Kids-Content-Studio.git

cd AI-Kids-Content-Studio

pip install -r requirements.txt

streamlit run app.py
```
